# Appointment Booking Website 📅

این پروژه یک وب‌سایت برای مدیریت رزرو نوبت است که با استفاده از Node.js ساخته شده است.

## 🚀 ویژگی‌ها

- ثبت‌نام و ورود کاربران با OTP
- احراز هویت با JWT
- مدیریت نقش‌ها و دسترسی‌ها (User / Barber / Admin)
- مدیریت پروفایل آرایشگران
- مدیریت خدمات و وضعیت فعال/غیرفعال بودن آن‌ها
- رزرو، لغو و مدیریت نوبت‌ها
- تأیید، رد و تکمیل نوبت توسط آرایشگر
- پنل مدیریت برای مدیریت آرایشگران و نوبت‌ها
- مدیریت پورتفولیو و تصاویر آرایشگران
- افزودن، حذف و جایگزینی تصاویر پورتفولیو
- سیستم کامنت برای پورتفولیو
- اعتبارسنجی ورودی‌ها با Yup
- آپلود و مدیریت تصاویر با Multer

## 🛠️ تکنولوژی‌های استفاده شده

- Node.js — محیط اجرای Backend
- Express.js — ساخت REST API و مدیریت Routeها
- MongoDB — دیتابیس
- Mongoose — ODM برای کار با MongoDB
- JWT (JSON Web Token) — احراز هویت و مدیریت دسترسی
- Multer — آپلود و مدیریت فایل‌های تصویری
- Yup — Validation ورودی‌ها
- bcrypt / bcryptjs — اگر برای Hash کردن پسورد استفاده کرده‌ای
- Redis — اگر همان سیستم OTP پروژه را همچنان داری
- dotenv — مدیریت Environment Variables
- CORS — مدیریت درخواست‌های Cross-Origin
